Основа: Paulos99/engels-ivanovo, коммит 13f062560aa85a93097bc5f9bd49703fa71f8082.
Локальная ветка: redesign/quiet-engels. Публикация не выполнялась.
Этот документ описывает актуальную реализацию и заменяет прежние рекомендации по композиции в art-direction.md и ui-spec.md.

## Что изменилось

- Главная: шесть секций вместо десяти. Первый экран с вертикальной фотографией, подборка кухни, кофе, интерьер, Telegram, контакты.
- Молочная и оливковая палитра; Lora и Manrope с кириллицей; уменьшены скругления и декоративные эффекты. Шрифты загружаются через Google Fonts, предусмотрены системные замены.
- Вертикальные интерьерные фотографии размещены в подходящих пропорциях; небольшие фото еды не растягиваются на всю ширину.
- Подборка из четырёх блюд берёт цены из общей базы меню. Фотографии еды иллюстративны, не выданы за снимки других конкретных блюд.
- Удалены с главной повторяющиеся вступление и философия, длинный список сезонных позиций, статичные новости и устаревший счётчик отзывов.
- Меню: кухня/напитки, поиск с учётом ё/е, категории, пустой результат, сброс поиска; все 84 позиции сохранены.
- Навигация учитывает префикс GitHub Pages. Переходы на категории открывают нужный раздел меню.
- Мобильное меню использует native dialog: фокус внутри окна, Escape, кнопка закрытия и блокировка прокрутки фона. Нижняя панель ведёт к меню и маршруту.
- Исправлены опечатки и единицы измерения. SEO URL соответствует настроенной публикации GitHub Pages; при смене домена нужно обновить index.html и src/data/site-config.ts.

## Проверка

- npx tsc --noEmit — успешно.
- GITHUB_PAGES=true npm run build — успешно.
- node scripts/check-redesign.mjs — проверяет ссылки с префиксом, состав главной, подборку, сохранность 84 уникальных позиций, кухню/бар и прямую ссылку на кофе.
- Дополнительно выполнены DOM-проверки с временной jsdom: переключение на напитки, поиск капучино, пустой результат и сброс. jsdom не добавлен в зависимости сайта. Для повторения: установить jsdom вне проекта и передать ENGELS_QA_DOM с абсолютным путём к jsdom/lib/api.js.
- Визуальная проверка в настоящем браузере не выполнена: удалённый браузер блокирует локальный адрес. После запуска проверить 390, 768 и 1440 px, загрузку шрифтов, кадрирование, мобильный диалог, поиск и переходы между страницами. До этой проверки результат не считается визуально утверждённым.
