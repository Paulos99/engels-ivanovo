# Изображения для сайта «Энгельс»

Добавьте фотографии в соответствующие папки и обновите пути в `src/data/images.ts`.

## Структура

```
public/images/
├── coffee/       — приготовление кофе, напитки
├── food/         — блюда, завтраки, десерты
├── interior/     — интерьер, пространство, бонсай
├── details/      — детали, материалы
└── people/       — гости, бариста (если нужно)
```

## Слоты (src/data/images.ts)

| Слот | Назначение | Рекомендуемый crop |
|------|------------|-------------------|
| hero | Первый экран | 16:10, landscape |
| coffee-hero | Раздел «Кофе» | 4:3 |
| food-1, food-2, food-3 | Гастрономия | 3:4 portrait |
| interior-main | Пространство | 16:10 |
| space-wide | Широкий кадр интерьера | 21:9 |

## Логотип

Поместите SVG или PNG в `public/logo.svg` и подключите в Header.

## После добавления

В `src/data/images.ts` для каждого слота укажите:

```typescript
src: '/images/interior/hero.jpg',
```
