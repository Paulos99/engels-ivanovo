# Brand Research — «Энгельс», Иваново

## Позиционирование

**ЭНГЕЛЬС** — спешелти-кофейня с авторской гастрономией в Иваново.

Три опоры бренда:
- **Кофе** — спешелти-зерно, эспрессо, фильтр, альтернативные способы, авторские напитки
- **Гастрономия** — авторская кухня: завтраки, основные блюда, десерты, сезонное
- **Пространство** — свет, дерево, природные материалы, спокойная атмосфера

Философский слой: **внимание к вкусу** — к кофе, еде, пространству.  
Подтекст: *«всё немного глубже, чем кажется»* — через визуал, не через слоганы.

## Tone of Voice

- Русский язык, короткие взрослые тексты
- Без рекламных клише («уникальный», «незабываемый», «лучший в городе»)
- Премиальность через качество исполнения, не через слова
- Английский — только в названиях продуктов/терминах specialty coffee

## Визуальный код (из брифа)

- Премиально, современно, спокойно, натурально — без показной роскоши
- Главный инструмент: **фотография + типографика + пространство**
- Избегать: золото, luxury-чёрный, неон, стеклянные карточки, шаблонный ресторанный UI
- Дерево-бонсай у барной стойки — ключевой элемент интерьера (подтверждено заказчиком)
- Восточная эстетика — тонко: естественность, созерцательность, баланс (без иероглифов и клише)

## Сильные стороны для сайта

- Specialty coffee + гастрономия + интерьер — три равноправных narrative
- Бонсай у барной стойки — уникальный визуальный якорь
- Живой Telegram-канал для блока «Сейчас в «Энгельсе»»
- Dog friendly — дифференциатор

## Обязательные элементы

- Hero с адресом и CTA «Смотреть меню» / «Построить маршрут»
- Разделы: Кофе, Гастрономия, Пространство, Меню, Контакты
- Полная страница `/menu` с категориями
- Фраза про бариста (подтверждено)
- Контакты: телефон, часы, Telegram, VK, Instagram, Яндекс Карты

## Запреты

- Не выдумывать цены, блюда, часы, адреса, историю, имена
- Не использовать меню engelscoffee.ru (Екатеринбург)
- Не использовать stock/AI-фото
- Не показывать 2GIS, WhatsApp (решение заказчика)
