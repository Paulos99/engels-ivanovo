# Визуальная корректировка по фотографиям интерьера

Этот документ заменяет направление materials-v2.md. Крупные текстурные заливки и наклонённые фотокарточки убраны. Сгенерированные материалы остаются в истории проекта, но не загружаются интерфейсом.

Акцент #AECF96 получен по медиане зелёных пикселей присланного JPEG логотипа (RGB 174, 207, 150). Это образец из растрового изображения, не утверждённый цвет из брендбука. На зелёных кнопках и вкладках используется тёмный текст.

Визуальные опоры: тёплая молочная поверхность, светло-серый фон раздела пространства, мягкие зелёные плоскости, асимметричная фотокомпозиция, геометрия арочных окон, тонкие линии и свободные поля. Изображения интерьера используются как референсы; прежние серые фотозаглушки сохранены. Одностраничная структура, модальное меню, поиск и 84 позиции не изменялись.
