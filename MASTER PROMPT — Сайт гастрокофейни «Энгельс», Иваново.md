# MASTER PROMPT — Сайт гастрокофейни «Энгельс», Иваново

## 0. РОЛЬ И ЗАДАЧА

Ты — Lead Web Designer + Creative Director + Senior Frontend Architect + QA Lead.

Твоя задача — спроектировать и реализовать премиальный имиджевый сайт для гастрокофейни **«Энгельс» в Иваново**.

Это реальный коммерческий бренд. Сайт должен восприниматься как сайт современного самостоятельного заведения высокого визуального и гастрономического уровня.

Главная задача сайта:

> За короткое время сформировать у посетителя ощущение, что «Энгельс» — особенное место в Иваново: спешелти-кофейня с серьёзным отношением к кофе, гастрономической кухней и тщательно созданной атмосферой пространства.

При этом сайт должен оставаться простым и понятным.

НЕ нужно превращать сайт в:
- энциклопедию specialty coffee;
- сложный интерактивный арт-проект;
- ресторанный каталог;
- перегруженный лендинг;
- набор маркетинговых лозунгов;
- демонстрацию технических возможностей.

Главный приоритет:

**ЭСТЕТИКА → ВПЕЧАТЛЕНИЕ → КОФЕ → ГАСТРОНОМИЯ → ПРОСТРАНСТВО → МЕНЮ → КОНТАКТ.**

# 1. КОНЦЕПЦИЯ БРЕНДА

Зафиксируй следующую смысловую основу.

## ЭНГЕЛЬС

**Спешелти-кофейня · гастрономия · Иваново**

Три главных элемента:

### КОФЕ
Спешелти-зерно, внимательное приготовление, фильтр, альтернативные способы, эспрессо, авторские напитки.

### ГАСТРОНОМИЯ
Авторская кухня, завтраки, основные блюда, десерты, сезонные предложения.

### ПРОСТРАНСТВО
Свет, дерево, природные элементы, интерьер, детали, спокойная атмосфера и ощущение места, в котором хочется остаться.

Философский слой бренда:

> **Внимание к вкусу.**
>
> К кофе.
> К еде.
> К пространству.

И дополнительная смысловая линия:

> **Всё немного глубже, чем кажется.**

Эта идея должна ощущаться через визуал, структуру и отдельные короткие тексты, но НЕ должна превращаться в навязчивый слоган.

# 2. ОСОБЕННОСТЬ ПРОСТРАНСТВА

В центре интерьера рядом с барной стойкой находится дерево, выполненное/оформленное в эстетике бонсай.

Это важный визуальный элемент пространства.

Не использовать банальные восточные клише:
- иероглифы;
- сакуру;
- красно-чёрную японскую палитру;
- декоративные паттерны;
- псевдоазиатскую типографику.

Восточная составляющая должна ощущаться тонко:

- естественность;
- созерцательность;
- внимание к форме;
- материалам;
- деталям;
- спокойствию;
- балансу.

Дерево должно восприниматься как часть реального интерьера, а не как декоративная иллюстрация.

# 3. ВИЗУАЛЬНОЕ НАПРАВЛЕНИЕ

Сайт должен выглядеть:

- премиально;

- утончённо;

- эстетично;

- шаблонные ресторанные UI;
- избыток скруглённых карточек.

### Главный инструмент визуальной коммуникации:

**качественная фотография + типографика + пространство + композиция.**

Фотографии должны занимать большую часть визуального поля.

# 6. МЕНЮ

Меню является полноценной частью сайта.

Не использовать PDF как основной вариант меню.

Не переписывать меню вручную из памяти.

Не выдумывать позиции.

Не сокращать меню до нескольких популярных блюд.

## Задача

Получить актуальное меню из:

https://engels.taplink.ws/

Необходимо:
1. изучить структуру Taplink;
2. определить все категории;
3. извлечь все позиции;
4. извлечь описания;
5. извлечь цены;
6. определить сезонные разделы;
7. сохранить структуру;
8. проверить данные;
9. подготовить меню как структурированные данные внутри проекта.

Если Taplink технически недоступен для автоматического чтения:
- не выдумывай данные;
- зафиксируй ограничение;
- предложи структуру файла данных;
- используй только доступную информацию;
- оставь чёткий TODO для ручного переноса.

Меню должно быть легко обновляемым.

Предпочтительно хранить его в отдельном структурированном файле, например:

`src/data/menu.ts`

или

`src/data/menu.json`

Структура должна позволять легко менять:
- название;
- описание;
- цену;
- категорию;
- изображение;
- наличие;
- сезонность.

# 11. АНИМАЦИЯ

Анимация должна быть очень сдержанной.

Использовать:
- мягкое появление;
- лёгкий scale фотографий;
- аккуратные hover states;
- плавный переход страниц;
- subtle parallax только там, где он действительно усиливает композицию.

Не использовать:
- постоянные вращения;
- чрезмерный parallax;
- сложные WebGL-сцены;
- анимацию ради демонстрации технологий.

Сайт должен ощущаться дорогим и спокойным.

# 18. SEO

Сайт должен иметь базовую SEO-структуру.

Title:

**Энгельс — спешелти-кофейня и гастрономия в Иваново**

Meta description — написать естественно, без SEO-спама.

Использовать:
- semantic HTML;
- H1;
- H2;
- alt для фотографий;
- Open Graph;
- favicon;
- structured data для LocalBusiness/Restaurant, если данные подтверждены;
- корректный canonical;
- sitemap при необходимости.

# 20. ФИНАЛЬНЫЙ РЕЗУЛЬТАТ

В результате должен получиться сайт, который при первом просмотре сообщает:

> **Это не очередная кофейня.**
>
> Здесь серьёзно относятся к кофе.
>
> Здесь есть гастрономическая кухня.
>
> Здесь есть собственная эстетика пространства.
>
> Здесь хочется побыть.

Но сайт не должен говорить это напрямую.

Посетитель должен **считать это самостоятельно из визуального и смыслового опыта**.

# 21. ПОРЯДОК РАБОТЫ В PLAN MODE

Сейчас НЕ начинай сразу писать код.

Сначала:

1. Проанализируй существующий проект и его структуру.

После утверждения плана переходи к реализации.
